# Café Aroma

Landing page de uma cafeteria artesanal fictícia, desenvolvida com **HTML, CSS e JavaScript**.

O projeto foi criado com foco em uma experiência visual elegante, utilizando uma identidade inspirada no processo de preparação de café, desde a infusão até a xícara.

## Sobre o projeto

O Café Aroma apresenta uma experiência visual baseada no conceito de **extração de café**.

A página possui diferentes seções que representam etapas desse processo:

* Infusão
* Despejo
* Extração
* Xícara

Além do conteúdo institucional da cafeteria, o projeto conta com animações e elementos interativos para tornar a navegação mais dinâmica.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Intersection Observer API
* CSS Animations
* CSS Grid
* CSS Variables

## Características

* Design inspirado em cafeterias artesanais
* Textura visual de papel
* Paleta de cores em tons de papel, café, cobre e verde-pátina
* Animações durante a rolagem
* Indicador de progresso da página
* Indicador da etapa atual da experiência
* Efeito de revelação dos elementos
* Layout responsivo
* Galeria de imagens
* Seção de história
* Seção de experiência
* Processo de preparação do café
* Área de contato

## Como executar

Não é necessário instalar dependências.

Basta baixar ou clonar o repositório e abrir o arquivo:

```text
index.html
```

Também é possível executar o projeto utilizando uma extensão como o **Live Server** no VS Code.

## Projeto

O Café Aroma foi desenvolvido como um projeto de estudo e portfólio para demonstrar conhecimentos em desenvolvimento front-end, principalmente em:

* Estruturação de páginas com HTML
* Estilização avançada com CSS
* Responsividade
* Animações
* Interações com JavaScript
* Manipulação do DOM
* Intersection Observer API
